# AI 小项目脑暴 · 小而精方向

> 目标：用 AI（大模型、本地模型、规则 + LLM 混合）做**边界清晰、一两周内可做出 MVP** 的东西。优先**解决一个具体痛点**，而不是「全能平台」。

---

## 调研结论（2025–2026 常见可行形态）

| 形态 | 适合做什么 | 技术栈参考 | 体量感 |
|------|------------|------------|--------|
| **网页 / PWA** | 工具站、个人面板、轻协作 | Next.js / Vite + 一处托管 API | 小，易分享 |
| **桌面小工具 (.exe)** | 常驻托盘、本地文件、离线优先 | Tauri / Electron + 小后端可选 | 中小，分发要签名 |
| **浏览器扩展** | 划词、页面摘要、表单辅助 | MV3 + 极简 popup | 很小，商店审核 |
| **CLI** | 开发者工作流、批处理 | Python / Go + 配置文件 | 极小 |
| **Bot（IM）** | 群内问答、提醒、日报 | Webhook + 无状态服务 | 小，依赖平台 |

**趋势简要**：多模态（图/表/PDF）+ **RAG 小知识库**很适合「个人/小团队」场景；完全自训模型不纳入本清单。

## 实用 App 向（手机 / PWA）

1. **「本周只吃这些」菜谱 + 采购清单**  
   输入忌口/人数/预算，生成 7 天菜谱与超市清单；可接条码扫描（后续迭代）。

2. **会议纪要 → 行动项**  
   粘贴文字或上传 txt，输出：决议、负责人、截止时间（结构化 JSON 可导出到备忘录）。

3. **习惯打卡 + 一句话日记**  
   每天一句 + AI 周回顾（情绪/主题词），数据全在本地或自建 SQLite。

4. **「读完这篇文章再划走」**  
   收藏链接，AI 生成 3 条自测题；答对才标记已读（防刷短视频式阅读）。

## 桌面 / .exe 小工具

1. **文件夹「智能重命名」**  
   选中文件，按规则批量改名（日期、项目名、哈希短前缀）；预览 diff 再执行。

2. **截图 → 自动 OCR + 进剪贴板**  
   全局快捷键，适合抄错误码、抄表格片段（可先做英文+中文）。

3. **本地日志/错误聚合**  
   拖入 `.log`，AI 归类 Top 原因 + 建议排查顺序（不上传全文时可只传摘要）。

4. **小词典 / 术语侧栏**  
   划词翻译 + 本领域术语表（JSON 维护），离线词库 + 在线补全。

---

## 网页 / 小站

1. **简历一页站 + 「针对 JD 改写要点」**  
   粘贴 JD，输出 5 条简历 bullet 建议（不自动造假，只重组表述）。

2. **正则 / Cron / JSON 小实验室**  
   输入即解释 + 常见坑提示；可接「用自然语言生成正则」作为增值。

3. **API 联调记事本**  
   保存请求模板、环境变量；一键生成 curl / fetch（AI 补全 Header 说明）。

4. **轻量团队「今日站会」页**  
   每人一句进度 + 阻塞，AI 合并成一段摘要邮件正文。

## 开发者向（更小）

1. **Git commit message 生成器（本地）**  
   `git diff` → 规范 message；可选 Conventional Commits。

2. **`.env.example` 生成器**  
   扫代码里的 `process.env.X`，生成带注释的 example（脱敏）。

3. **OpenAPI / 类型同步检查**  
   对比前端类型与 swagger，输出差异报告（规则为主，AI 解释）。

---

## 选题过滤器（用来砍掉大项目）

- [ ] 能否用 **一句话** 说清用户是谁、解决什么？
- [ ] MVP 是否 **≤ 3 个核心界面**（或 ≤ 5 个 CLI 子命令）？
- [ ] 数据能否先 **文件/SQLite**，推迟账号系统？
- [ ] 是否 **不依赖** 训练新模型，只用 API 或本地 7B 级推理即可？

五条里有一条过不去，就拆小或换题。

## 建议的下一步（从本仓库出发）

1. 在上面列表里 **标星 2～3 个** 最有感觉的方向。  
2. 每个方向写 **半页 PRD**：用户、场景、第一条用户路径、不做清单。  
3. 选一个做 **1 周 spike**：能点、能跑、能演示即可。
